# 按注释批量修改

## 用途

按完整注释找到对象，依照表格移动、改 T 值、改 CMYK 色值或删除。

## 准备

先用“集体注释”生成注释。点击说明顶部的“变量”按钮打开表格，手动填入需要修改的完整注释，每行一条规则。

## 操作

1. “操作”填：移动、改T值、改色值或删除。
2. 移动填 X毫米、Y毫米，正数向右、向上，负数反向；改T值填 T值；改色值填 C、M、Y、K。颜色数值均为 0–100。
3. 改T值、改色值可选“填充”“描边”或“填充和描边”，留空默认两者；删除只填注释和操作。
4. 保存为 CSV UTF-8，运行脚本并检查结果。单文件需手动保存；批处理时勾选“保存源文件”。

## 注意

注释需完全一致，规则从上到下执行，重复运行会再次移动。改色值只支持 CMYK 文档中的普通四色，遇到专色或全局色会报错弹窗，停止当前文件。正常执行无弹窗；隐藏、锁定状态会恢复，批处理跳过 link／links。匹配和错误详情见脚本旁的“执行报告”文件夹。Excel 下拉模板填写后也要另存为 CSV，不能直接读取 XLSX。
