# 跨文件提取并替换

## 用途

从模板提取对象，放到当前文档的指定画板，并可删除旧对象。

## 准备

先保存并关闭模板，打开目标 AI 的副本。编辑 `跨文件提取并替换.csv`；第一行写 `模板,模板AI绝对路径`。

## 操作

1. 第二行保留“复制,替换,删除”列名，每三列一组。
2. 第三行依次写“来源顶层图层、目标顶层图层、待删顶层图层”。
3. 第四行依次写“来源对象、目标画板名称或编号、待删对象”；更深路径继续向下填写，删除列可留空。
4. 保存表格并运行，核对对象、位置和删除范围。

## 注意

路径按名称规范化后精确匹配；不会再全文档模糊删除。模板打开与复制路径检查通过后才处理。运行出错可能已完成部分操作，请用副本测试；不自动保存。
