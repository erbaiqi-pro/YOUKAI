YOUKAI 1.0.0 - Stable release
Author: 二百七

Includes 26 tools. The PDF export tool has been removed. Categories are unchanged.

Save work and exit Adobe apps before running the full installer. Previous installations and custom scripts are backed up under %LOCALAPPDATA%\YOUKAI\backups. External CSV files are kept. The full installer resets panel settings; select paths again after installation.

The one-time online upgrade from test builds preserves paths and upgrades the updater. Later 1.0.x updates contain scripts, guides, templates and release metadata only. Larger versions require a full installer from the author's website. Updates are optional and use a red NEW badge without automatic dialogs.
