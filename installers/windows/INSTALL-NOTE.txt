YOUKAI 1.0 · 内部测试版
作者：二百七

内置 27 个脚本，新增集体注释、按注释批量修改和自愿联网更新。

1.0.1 修复 Illustrator 2026 中引擎无法加载的问题，更新检查改为读取公开发布清单，避免依赖 API 查询额度。

安装前请保存工作，并完全退出 Illustrator、Photoshop、InDesign。

安装程序会先备份并清理当前用户及公共目录中的旧版 YOUKAI，再安装新版。
备份位置：%LOCALAPPDATA%\YOUKAI\backups
旧版内的自定义脚本会保留在备份中，需要时单独复制回来。

外部 CSV 和设计文件保留。面板设置恢复默认；首次使用请重新选择自己的 CSV 目录。
清理公共目录旧版时会请求管理员授权。新版始终安装给启动安装程序的当前用户。

本版为内测版本，首次运行请用设计文件副本试用。联网更新只显示红色 NEW，不自动弹窗或强制更新。
