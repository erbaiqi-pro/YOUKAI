# 隐私与密钥

YOUKAI 的普通脚本在本地 Illustrator 中处理文件，不需要 API Key。

## 联网范围

- 更新器只从 `erbaiqi-pro/YOUKAI` 的公开 GitHub 发布读取版本、清单和更新文件，使用 HTTPS；不发送 AI 文件、CSV、对象注释或本机凭据。
- 访问网站 LOGO 时，会打开作者博客 `https://erbaiqi.pages.dev/`。更新说明按钮打开对应 GitHub 发布页。
- GitHub 和网站会收到网络访问通常携带的 IP、User-Agent 等信息；YOUKAI 没有加入遥测、统计上报或设计稿上传接口。

## 本地保存

用户 CSV、路径设置、运行报告和更新备份保存在本机。报告可能包含文件路径、对象注释和错误原因，分享报告前可先检查内容。源码导出不包含“项目资料”、个人表格、执行报告或安装标记。

作者署名“二百七”、GitHub 账号和作者网站属于主动公开的项目信息。安装器中的第三方作者和译者署名按原样保留。

## 发布前检查

`tools/check-public-privacy.py` 检查常见密钥、Token、私钥头、带凭据的 URL 和敏感文件名；更新包和开源源码构建都会执行检查。报告只显示位置和指纹，不打印疑似密钥原文。

该检查是辅助筛查，不能保证识别所有编码、拆分或隐藏的密钥。不要把私人密钥写入 JSX、HTML、JavaScript、CSV 或安装包；`.gitignore` 也不会移除已经存在于 Git 历史里的内容。

自定义脚本和后续更新会以本地脚本权限运行，应使用可信来源并保护发布账号。如果未来功能需要私有服务凭据，应单独设计服务端或本机凭据存储，避免将凭据随开源代码分发。
