# YOUKAI 1.0 更新记录

2026-11-04 · 1.0.1 内测修复 · 作者二百七

- 修复宿主桥接中的路径正则不兼容 ExtendScript，导致“引擎未就绪/语法错误”的问题。已在 Illustrator 2026（30.0.0）复现旧错误并验证修复后的编译、桥接加载及 PONG；27 个工具脚本内容保持不变。
- 更新检查直接读取 GitHub 正式发布的公开清单，移除对 REST API 查询额度的依赖，不使用 API Key；区分 403 拒绝访问、请求限流和连接失败，并遵守限流冷却时间。
- 无正式更新清单时显示暂无可用更新。没有自动弹窗；用户仍可继续使用当前工具。
- 增加真实 Illustrator 宿主检查命令，构建版本号与安装包文件名随程序版本同步。
