# YOUKAI 联网更新

仓库：[erbaiqi-pro/YOUKAI](https://github.com/erbaiqi-pro/YOUKAI)。当前版本为 1.0.1，27 个脚本，修复首包的宿主语法兼容和更新检查问题。宿主加载已在 Illustrator 2026 验证；完整画稿流程仍需试用。自动检查针对后续正式发布，内测发布不会触发正式更新提示。

## 用户怎么更新

1. 安装一次带更新功能的 YOUKAI。
2. 打开面板后自动检查；有新版时，网站 LOGO 旁显示红色 `NEW`。
3. 想更新时点击 `NEW`，再点“立即更新”。不更新也可以继续使用。
4. 等待完成，点击“重新加载”。

没有自动更新弹窗。网络不可用时不影响脚本使用。系统设置里可以点“检查更新”；自动检查最多每 6 小时联网一次。

检查直接读取 GitHub 的 `releases/latest/download/YOUKAI-Update.json`，不查询 REST API，也不需要 Token。没有正式更新文件时显示“暂无可用更新”；403 会说明访问被拒绝或请求受限。请求受限时遵守服务端给出的重试时间，不连续重试。

更新会保留用户 CSV、个人脚本、执行报告、安装标记和面板设置。个人文件与新增官方文件同名时会停止更新，先改名再重试；已修改过的官方脚本会用新版替换，旧内容保存在完整备份里。运行脚本、批处理时不能更新。开发源码目录不会被在线更新覆盖。

## 作者怎么发布下一版

1. 修改 `com.youkai.toolbox/release.json` 的版本号，例如 `1.1.0`；同步 `CSXS/manifest.xml` 的两个扩展版本和 `package.json`。使用正式版本号 `主版本.次版本.修订号`。
2. 在 AI 副本中验收脚本。运行 `npm test` 和 `npm run test:ui`，并完成一次真实 CEP 安装目录中的更新试用。
3. 运行 `python tools/build-update.py`。在“项目资料/发布准备/联网更新”生成两个文件：`YOUKAI-Update.json` 和 `YOUKAI-Update-版本号.zip`。需要首装 EXE 时再单独构建安装包。
4. GitHub 仓库右侧进入 Releases，创建标签 `v版本号` 的正式发布，写更新说明，将这两个文件作为附件一起上传，再发布。两个文件必须来自同一次构建；源码 ZIP 不能代替更新 ZIP。
5. 安装前一版本，在面板中点“检查更新”，验证红标、主动更新、个人表格保留、重新加载和失败回滚，再录制教程。

GitHub 的正式发布接口提供版本和附件下载地址；公开发布不需要在插件内放账号或令牌。[发布文档](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository)、[接口文档](https://docs.github.com/en/rest/releases/releases)。

## 备份和恢复

更新前将新程序准备好，核对 ZIP 的 SHA256、逐文件清单、路径、插件身份、版本和脚本数量。只接受指定仓库的 HTTPS 更新文件；不接受外部下载地址、路径越界、重复文件名、符号链接或加密 ZIP。下载失败不会修改现有程序，替换或校验失败会尝试恢复旧目录。

完整旧版放在当前 CEP 目录旁的 `YOUKAI-update-backups/时间-编号-previous`。备份不会自动删除。系统目录没有写入权限时，本次更新会停止，可改用用户目录中的安装版本。

如果更新过程中遇到断电或 Adobe 被强制结束，先重新打开面板，让恢复记录完成检查。若安装目录缺失导致面板无法打开，关闭 Adobe，将上述 `previous` 目录恢复到原来的扩展目录名称；恢复前保留现场文件。本轮自动检查覆盖文件替换失败、校验失败和中断恢复，尚不能代替各 Illustrator 版本、Windows/macOS 中的真实试用。

## 上传源码

运行 `python tools/build-github.py` 重新整理“开源部分”，上传该目录内部内容。不要上传整个工作目录或“项目资料”。`.gitattributes` 为程序目录保留原始字节，避免 Git 换行转换破坏已验收脚本和发布校验。此工具只整理本地文件，不上传、不创建 GitHub 发布。
